# How to get google-services.json

1.  Go to the [Firebase console](https://console.firebase.google.com/).
2.  Create a new project or select an existing one.
3.  In the project overview, click the Android icon to add an Android app to your project.
4.  Follow the setup instructions. You will be prompted to download a `google-services.json` file.
5.  Place the downloaded `google-services.json` file in this directory (`android/app`).
